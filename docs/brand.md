# AIHCN · 智衡 — 品牌战略（中英并重）

> 版本：v3.0（2026-08） · 方向：双市场（中国 + 海外），双语站点

## 1. 品牌一句话

- 中文：**实用的 AI 工具，省下的时间远超订阅价。**
- English：**Practical AI tools that pay for themselves.**

面向视频创作者与独立制作者的 AI 工具工作室。中国与海外市场并重，双语站点（`/zh/` + `/en/`），按市场分别定价与收款。

## 3. 双市场定位

| 维度 | 中国市场 | 海外市场 |
|---|---|---|
| 人群 | 抖音 / B站 / 小红书 / 视频号创作者 | YouTube / TikTok / Shorts 创作者 |
| 定价 | ¥19-49 / 月 | $9-19 / 月 |
| 收款 | 支付宝 / 微信支付 | Paddle / Lemon Squeezy |
| 获客 | 小红书 / 抖音 / B站 / 私域 | Google SEO / Reddit / X |
| 内容 | 中文博客 | 英文博客（二期启动） |

- 选中国市场：母语运营、创作者基数大、支付链路有经验（已有支付宝 + Stripe 收款实践）
- 选海外市场：客单价高、订阅生态成熟、避免国内红海
- **并重不等于同时用力**：产品与站点并重，内容运营错峰——先中文内容跑 3 个月验证，再启动英文内容

## 5. 收款与合规

- 国内：支付宝 / 微信支付需要商户主体（个体工商户或企业）——列入待办，不阻塞建站
- 海外：Paddle / Lemon Squeezy（merchant of record，无需海外主体）
- 政策页（隐私 / 退款 / ToS）需中英双语，上线前补齐
- 中文站面向大陆用户需评估访问速度（Cloudflare 免费版无大陆节点）与备案；不接入大陆服务器则无需 ICP

## 6. 视觉方向（沿用）

设计系统不变：宣纸白 / 墨黑 / 青金石蓝 / 朱砂红 + 像素「A」+ 终端风格；文案双语，状态诚实（开发中 / 调研中 / 撰写中如实标注）。
