# AIHCN · 智衡 — 商业模式（中英并重）

> 版本：v3.0（2026-08） · 目标：12 个月内中英合计 MRR ≥ ¥5,000 + $500

## 1. 核心逻辑

一个产品团队，两个市场，双语站点。中国与海外共用同一套工具与品牌，按市场分价、分收款、分获客。内容运营错峰：先中文验证，再补英文，避免双倍精力同时铺开。

## 2. 收入模型

| 市场 | 工具 | 月价 | 年付 | 收款 | 启动顺序 |
|---|---|---|---|---|---|
| 中国 | 转写工坊 | ¥19 | ¥190 | 支付宝/微信 | 第 1 个 |
| 中国 | 切片工坊 | ¥39 | ¥390 | 支付宝/微信 | 第 2-3 个 |
| 中国 | 文案工坊 | ¥29 | ¥290 | 支付宝/微信 | 第 2-3 个 |
| 海外 | Transcriptor / ClipLab / MetaForge | $9-19 | $90-180 | Paddle | 与国内并行 |

补充收入：博客联盟佣金（中英双向，占比小，锦上添花）。

## 3. 分阶段路径

### 阶段 0：双语品牌上线（第 1 个月）
- `/zh/` + `/en/` 双语站上线，根域名语言跳转
- 等待列表 + 邮箱链路打通
- 关键指标：等待列表 ≥ 50 邮箱（中文渠道优先）

### 阶段 1：第一个工具 MVP（第 2-3 个月）
- 开发等待人数最多的工具（预计转写工坊），1 个核心场景
- 收款：国内支付宝/微信（需商户主体，如无则先用海外 Paddle 兜底）+ Paddle
- 关键指标：付费用户 ≥ 20，MRR ≥ ¥1,000 + $100

### 阶段 2：中文内容放大（第 3-6 个月）
- 中文博客每周 1-2 篇 SEO 内容；小红书/抖音/B站分发
- 关键指标：中文站月访问 ≥ 3k，MRR ≥ ¥3,000 + $300

### 阶段 3：英文内容启动 + 第二工具（第 6-12 个月）
- 英文博客每周 1 篇；产品页承接 Google 流量
- 用第一工具的收入与反馈决定第二工具
- 关键指标：MRR ≥ ¥5,000 + $500，年化 ≥ ¥60k + $6k

## 4. 成本结构

| 项目 | 成本 |
|---|---|
| 域名 aihcn.com | 已持有（年续费约 $10） |
| Cloudflare 免费版（Pages + Worker + D1） | $0 |
| 收款手续费 | 支付宝/微信约 0.6%-1% + Paddle 约 5% + 交易费 |
| AI API 额度（开发/运行） | $20-100/月起 |
| 合计 | 极低，API 是主要可变成本 |

## 5. 关键风险与对策

| 风险 | 对策 |
|---|---|
| 双语内容双倍精力 | 产品与站并重，内容错峰：先中文 3 个月，再英文 |
| 支付宝/微信需商户主体 | 用个体工商户办理；未办好前用 Paddle 收款兜底 |
| 创作者工具竞争激烈 | 窄场景做深；差异化在"简单 + 诚实 + 便宜" |
| 等待列表不增长 | 1 个月 <50 邮箱就换场景或工具方向，不硬做 |
| 独立开发产能有限 | 一次只做一个工具；订阅优先，不做免费版养用户 |
